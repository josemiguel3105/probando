PRACTICA 1

Configurar el menú de GRUB para que el tiempo de espera sea de 20 segundos:

# Editar el archivo de configuración de GRUB
sudo nano /etc/default/grub

# Buscar la línea:
GRUB_TIMEOUT=5

# Cambiarla por:
GRUB_TIMEOUT=20

# Guardar cambios y actualizar GRUB
sudo update-grub

# Mostrar el resultado:
grep GRUB_TIMEOUT /etc/default/grub

Resultado esperado:
GRUB_TIMEOUT=20

---

Método de recuperación si olvidé la contraseña del usuario root:

# En el menú de GRUB:
1. Seleccionar la opción avanzada de arranque.
2. Elegir "Recovery mode" y entrar en modo root shell.
3. Montar el sistema en modo lectura/escritura:
   mount -o remount,rw /
4. Cambiar la contraseña del root:
   passwd root
5. Ingresar la nueva contraseña y reiniciar:
   reboot

PRACTICA 2


Script para hacer backup con TAR de la carpeta /home/jose:

# Crear el script
nano backup_home.sh

# Contenido del script:
#!/bin/bash
FECHA=$(date +"%d-%m-%Y_%H-%M")
tar -czvf /home/jose/backup_$FECHA.tar.gz /home/jose
echo "Backup completado: /home/jose/backup_$FECHA.tar.gz"

# Darle permisos de ejecución
chmod +x backup_home.sh

# Ejecutar el script
./backup_home.sh

---

Script que copie el resultado de ifconfig al escritorio:

nano guardar_ifconfig.sh

# Contenido del script:
#!/bin/bash
read -p "Ingrese el nombre del archivo: " nombre
ifconfig > /home/jose/Escritorio/${nombre}.txt
echo "Archivo creado en el Escritorio con el nombre: ${nombre}.txt"

# Dar permisos y ejecutar
chmod +x guardar_ifconfig.sh
./guardar_ifconfig.sh

PRACTICA 3


Configurar VM en modo Bridge:
- En VirtualBox / VMware, cambiar el adaptador de red a "Bridge Adapter".
- Guardar cambios y reiniciar la máquina virtual.

# Validar conexión desde Windows:
En el CMD de Windows:
ping 10.0.0.193

Resultado esperado:
Respuestas exitosas con tiempo en ms.

---

Habilitar servicio SSH en ParrotOS:

sudo systemctl enable ssh
sudo systemctl start ssh
sudo systemctl status ssh

# Probar conexión desde Windows:
ssh jose@10.0.0.193

---

Generar par de llaves SSH en Windows:

En PowerShell o CMD:
ssh-keygen

# Dejar vacío el passphrase y elegir destino, por ejemplo:
C:\\Users\\tu_usuario\\.ssh\\id_rsa

---

Copiar la llave pública al servidor ParrotOS:

scp C:\\Users\\tu_usuario\\.ssh\\id_rsa.pub jose@10.0.0.193:/home/jose/.ssh/authorized_keys

O desde Windows PowerShell:
type $env:USERPROFILE\\.ssh\\id_rsa.pub | ssh jose@10.0.0.193 "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"

---

Probar conexión sin contraseña:

ssh jose@10.0.0.193

# Resultado esperado:
Acceso directo al sistema sin solicitar credenciales.
